# Sicurezza

LinkeMap usa la tua sessione LinkedIn (cookie `JSESSIONID`) solo dentro la scheda di LinkedIn e
salva i dati solo in `chrome.storage.local` del tuo browser.

## Segnalare una vulnerabilità

Non aprire una issue pubblica. Usa **Security → Report a vulnerability** nella pagina GitHub
del progetto (segnalazione privata). Rispondo appena possibile.

Versioni supportate: solo l'ultima release.
